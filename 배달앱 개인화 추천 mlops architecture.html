02
MLOps 핵심 프로세스 — 5가지 자동화 루프
A
실시간 추론 루프
3초 주기
  • Dash dcc.Interval 타이머 3초마다 자동 실행
  • 가상 상황 랜덤 생성 (날씨·시간대·연령·성별·직업·지역·주말여부·메뉴) → api:8000/predict POST 요청
  • api → serving:8080/inference로 추론 요청 전달
  • LightGBM Score 계산 → Top 1 메뉴 반환
  • 20% 노이즈 추가 후 DB INSERT 피드백 적재
  • Dash 그래프 & 테이블에 실시간 플로팅
B
수동 앱 테스트
사용자 트리거
  • 드롭다운에서 날씨 / 시간대 / 연령 / 성별 / 직업 / 지역 / 주말여부 직접 선택
  • [수동 예측 요청] 클릭 → 즉시 동기 추론 실행
  • 추천 메뉴 + 확률 결과 회색박스에 즉시 출력
  • 로그에 🔴 [수동] 빨간 태그 & 마커로 구분 누적
  • 수동 결과도 DB INSERT로 이력 저장
C
데이터 드리프트 감지
20초 주기
  • worker 내부 BackgroundScheduler 20초마다 자동 실행
  • DB SELECT 최근 데이터 → PSI 점수 계산
  • 임계치 0.25 초과 → 드리프트 감지 판정
  • 감지 시 모델 자동 재학습 함수 트리거
  • [수동 드리프트 검사] 버튼으로 즉시 강제 실행 가능
D
자동 / 수동 CT 재학습
드리프트 감지 시
  • DB SELECT … ORDER BY id DESC LIMIT 1000
  • 최신 1000개 데이터로 Sklearn Pipeline Re-fitting
  • 학습 완료 → model_v1.pkl 볼륨에 덮어쓰기
  • serving 컨테이너에 갱신 신호 → Hot-swap 로드 (CD)
  • [수동 모델 재학습] 버튼으로 즉시 강제 실행 가능
E
시스템 운영 감사 로그 (Audit History)
이벤트 발생 시 누적
  • 시스템 제어판 버튼 클릭마다 알림 메시지 생성
  • 리스트 구조로 최신순 상단 누적 — 휘발 없음
  • 스크롤 영역으로 전체 이력 확인 가능
  • 드리프트 · 재학습 · 수동 요청 등 모든 이벤트 기록
03
이 구조가 주는 3가지 핵심 차별점
🛡️
FAULT ISOLATION
완벽한 장애 격리
재학습(CT) 도중 CPU가 100%를 찍어도 serving은 독립 실행되므로 사용자가 받는 추론 속도에 미세한 딜레이조차 없습니다.
📈
INDEPENDENT SCALING
독립적 확장성
트래픽 폭증 시 가벼운 api 컨테이너만 복제하고, 무거운 ML 연산은 serving 한 대에 집중. 비용 효율적 인프라 운영이 가능합니다.
🏭
PRODUCTION STANDARD
현업 표준 아키텍처
Online Serving / Offline Training 분리 구조는 대기업 상용 환경 그대로를 축소 복사한 완성도 높은 MLOps 표준 설계입니다.
